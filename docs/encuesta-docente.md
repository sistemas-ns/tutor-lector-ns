## F. Validación de criterios

Proponemos seis criterios para juzgar si la respuesta de un tutor de IA ayuda a aprender. Para cada uno indique qué tan relevante le parece para evaluar un buen turno de tutoría lectora: 1 = no relevante, 2 = poco relevante, 3 = bastante relevante, 4 = muy relevante.

**F1. No da la respuesta.** El tutor no entrega, confirma ni reformula la respuesta: la respuesta debe producirla el estudiante.  
*Relevancia:* 1 / 2 / 3 / 4

**F2. Una pregunta o pista por turno.** Cada intervención contiene una sola pregunta o una sola pista, no un cuestionario.  
*Relevancia:* 1 / 2 / 3 / 4

**F3. Anclaje al texto.** El tutor dirige al estudiante a una parte concreta del texto que está leyendo.  
*Relevancia:* 1 / 2 / 3 / 4

**F4. Nivel adecuado.** La pregunta corresponde al nivel de comprensión (literal, inferencial, crítico) y solo avanza cuando el anterior está dominado.  
*Relevancia:* 1 / 2 / 3 / 4

**F5. Tono.** Elogio específico en lugar de elogio vacío; reduce la dificultad ante la frustración sin regañar.  
*Relevancia:* 1 / 2 / 3 / 4

**F6. Brevedad.** Intervenciones cortas (máximo unas 60 palabras): quien debe hablar y pensar es el estudiante.  
*Relevancia:* 1 / 2 / 3 / 4
